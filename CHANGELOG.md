# Changelog

## [1.0.0] - 2026-08-15

First stable release. Adds a `version` and `description` to the manifest.

### Provides
- Custom prop models: tipis, wikiups, ini-pi structures
- Model registration for the `da_dev` object browser

### Notes
- Stream-only resource. Stream files require a full server restart, not
  `restart da_props`.
